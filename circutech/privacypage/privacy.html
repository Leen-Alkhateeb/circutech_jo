Privacy information

What this browser-based CircuTech demo stores and what it does not send.

This notice describes behavior found in the current project. It is a basic project notice, not legal advice or a final company policy; it must be reviewed before production use.

Browser storage

Account records, marketplace listings, cart contents, scans, unique article reads, rewards, preferences, and some dashboard data are stored in this browser using local storage. Sign-in session information is kept in session storage. This project has no connected application server or shared database, so this information does not automatically sync to another device.

Cookie consent choices are saved in local storage. The website currently does not include analytics or advertising integrations; selecting those optional categories does not activate a tracking service.

Account roles and security

Role checks in this prototype read browser storage and control the visible routes. Browser storage can be changed by its user, so these client-side checks do not provide production security. A deployed service must verify sessions and permissions on a trusted backend before protecting accounts or administrative data.

Forms and payments

The contact form is in demo mode and does not send messages to a server. Marketplace listings and reservations are local demo interactions. No payment provider is configured, and the site does not collect card numbers or CVVs or confirm paid orders.

External maps

The dashboard can display an embedded Google Maps location and directions links. Opening those features sends a request to Google Maps, which is governed by Google's own privacy terms.

Your controls

Dashboard Settings lets signed-in users download their locally stored account data, clear scans, unique article reads, and vouchers, or delete their account and associated browser records. You can also remove browser-stored marketplace listings and cart items. Clearing this website's browser storage removes remaining local data.

Contact and review

For questions about this project notice, use the contact page. Before launch, the site owner should confirm retention periods, processors, jurisdiction-specific disclosures, and the final privacy policy.
